# shorts-cutter

Режет длинное видео (по ссылке на YouTube или по локальному файлу) на
вертикальные шортсы 1080×1920 с вшитыми субтитрами и плашкой-заголовком.

## Что нужно

- Python 3.10+
- Дальше — двойной клик по `Установить.cmd`: сам создаст `.venv`, поставит
  `yt-dlp`/`faster-whisper`/`ctranslate2` из `requirements.txt` и попробует
  поставить [ffmpeg](https://ffmpeg.org) через `winget`, если его ещё нет.
  Ручной вариант, если `Установить.cmd` почему-то не подходит:
  ```
  python -m venv .venv
  .venv\Scripts\pip install -r requirements.txt
  winget install Gyan.FFmpeg
  ```
  (ffmpeg не обязан быть от winget — скрипт сам поищет его в PATH и в папке
  winget, либо укажи `--ffmpeg`)
- `faster-whisper` — локальное распознавание речи, когда у ролика нет
  авторских субтитров на YouTube. На NVIDIA GPU (проверено на RTX 3060 Ti) —
  быстро: 10 минут звука распознаются за ~23 секунды.
- Модель для отбора и судьи — не обязательна, но без неё отбор идёт по
  формуле, а не по смыслу. Два варианта на выбор:
  - [Ollama](https://ollama.com) с моделью `qwen2.5:7b-instruct-q4_K_M` —
    локально, без интернета и без ключей:
    ```
    ollama pull qwen2.5:7b-instruct-q4_K_M
    ```
  - Groq (облако, бесплатная квота) — ключ в поле окна или в
    `work/groq-key.txt`.

## Проще всего — по ярлыку

Один раз — `Установить.cmd`. Дальше двойной клик по `Шортсы.cmd` (или по
ярлыку на рабочем столе) — консоль, спросит по шагам: ссылка, режим выбора
моментов, вид кадра. `Окно.cmd` — то же самое, но в окне с чекбоксами
(`gui.py`), без консоли.

Готовые ролики лягут в папку `shorts/`, каждый ролик — в своей подпапке по
названию видео.

## Как это устроено

1. **Текст.** Сначала — авторские субтитры YouTube (только они, не
   автоматические — у автоматических нет пунктуации, а по ней ищутся
   границы). Нет авторских — автоматический переход на Whisper, результат
   кэшируется в `work/<id>/whisper-<model>.json`.
2. **Кандидаты.** Ролик режется на скользящие окна 25–105 секунд: начало —
   на границе предложения, конец — самый дальний конец предложения внутри
   коридора. Не нашлось такой границы — окно не строится вовсе (лучше
   меньше моментов, чем один срезанный криво).
3. **Плашка.** Заголовок главы, в которую попадает бо́льшая часть окна
   (дословно, не переписывается) → если глав нет — первый вопрос ведущего
   в начале окна → иначе пусто.
4. **Отбор.** Без модели — по формуле (длина, факт-плотность, вопрос в
   начале, живой звук). С моделью (Ollama или Groq) — модель ранжирует и
   при возможности проверяет уже отобранное вторым проходом.
5. **Кадр и рендер.** Раскладка по числу говорящих (blur — один в кадре
   на размытом фоне; stack — несколько тайлов друг над другом), субтитры
   вшиваются как `.ass`, кодирование через `h264_nvenc` (потолок битрейта
   считается от битрейта исходника, не фиксированная константа).

## Два режима

### Автомат — кинул ссылку, забрал шортсы

```
python cut.py auto https://youtu.be/VIDEO_ID --count 3
```

Ссылок можно передать сразу несколько. Скрипт скачает текст (субтитры или
распознает сам), выберет моменты, скачает видео и нарежет. Всё складывается
в `shorts/`.

### Вручную — сам смотришь, что предлагают

```
python cut.py scan https://youtu.be/VIDEO_ID
```

Покажет опорные слова видео и пронумерованный список моментов с расшифровкой.
Выбираешь номер и режешь:

```
python cut.py cut https://youtu.be/VIDEO_ID --pick 3
```

## Кэш

Всё, что скачано и распознано, оседает в `work/<video_id>/` — исходник,
звуковая дорожка, субтитры, кэш расшифровки Whisper. При повторном прогоне
того же ролика ничего не скачивается и не распознаётся заново.
